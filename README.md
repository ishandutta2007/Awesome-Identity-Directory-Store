## 🌟 Overview & Top Identity Directory Store Ecosystem

**A Curated List of Enterprise SaaS Products, Self-Hosted Directory Services, Open-Source IAM Platforms, and LDAP Directory Servers** 🚀

*Focused on User Stores, Directory Services, Authentication Providers & Self-Hosted IAM Solutions.*

**Last updated: October 2026** 📅

This repository tracks notable **commercial identity directory platforms** and **open-source software** that store and manage user identities, credentials, user groups, and organizational hierarchies — powering authentication, authorization, SCIM provisioning, and single sign-on (SSO) across enterprise and customer-facing (CIAM) applications. 🌐

## 🔓 Open-Source GitHub Projects (Sorted by Stars)

Open-source identity directory stores and self-hosted IAM platforms offer enterprise sovereignty, privacy compliance, and developer control. Below is a curated list of top open-source repositories **sorted in descending order by GitHub Stars_Count** 🌟.

- **[Keycloak](https://github.com/keycloak/keycloak)** [![Stars](https://img.shields.io/github/stars/keycloak/keycloak?style=social&color=white)](https://github.com/keycloak/keycloak/stargazers) 🔑
  - **Open-source identity and access management solution** for modern applications and services, Apache-2.0 licensed.
  - **Features**: User federation (LDAP/Active Directory), OpenID Connect (OIDC), SAML 2.0, fine-grained authorization, WebAuthn passkeys, identity brokering, and customizable themes.
  - **Best for**: Enterprise-grade identity provider & single sign-on (SSO) infrastructure.

- **[Authelia](https://github.com/authelia/authelia)** [![Stars](https://img.shields.io/github/stars/authelia/authelia?style=social&color=white)](https://github.com/authelia/authelia/stargazers) 🛡️
  - **Open-source authentication and authorization server** providing 2FA and SSO via web reverse proxies (Nginx, Traefik, Caddy), Apache-2.0 licensed.
  - **Features**: Multi-factor authentication (Security Keys/FIDO2, TOTP, Duo), OpenID Connect provider, user directory integration (LDAP, file-based), and password reset workflows.
  - **Best for**: Self-hosted home labs and proxy-integrated web application access security.

- **[authentik](https://github.com/goauthentik/authentik)** [![Stars](https://img.shields.io/github/stars/goauthentik/authentik?style=social&color=white)](https://github.com/goauthentik/authentik/stargazers) 🌀
  - **Unifying identity provider** focused on flexibility and versatility, GPL-3.0 licensed.
  - **Features**: Support for OAuth2/OIDC, SAML, LDAP server interface, RADIUS, passwordless WebAuthn, stage-based flow engine, user self-service portal, and built-in proxy provider.
  - **Best for**: Modern self-hosted identity hub and versatile enterprise SSO replacement.

- **[SuperTokens](https://github.com/supertokens/supertokens-core)** [![Stars](https://img.shields.io/github/stars/supertokens/supertokens-core?style=social&color=white)](https://github.com/supertokens/supertokens-core/stargazers) 🚀
  - **Open-source Auth0 alternative** providing developer-first authentication SDKs, Apache-2.0 licensed.
  - **Features**: Session management, passwordless/OTP login, social authentications (OAuth 2.0), email/password, MFA, multi-tenancy, and pre-built frontend UI components (React, Vue, Angular).
  - **Best for**: Web and mobile developers embedding full-stack user authentication directly into codebases.

- **[Logto](https://github.com/logto-io/logto)** [![Stars](https://img.shields.io/github/stars/logto-io/logto?style=social&color=white)](https://github.com/logto-io/logto/stargazers) 🦜
  - **Open-source identity and access management platform** for developers, MPL-2.0 licensed.
  - **Features**: OIDC authentication, passwordless & social logins (Google, Apple, GitHub), Role-Based Access Control (RBAC), multi-tenancy support for B2B SaaS, audit logs, and embeddable sign-in UI.
  - **Best for**: Modern developer-friendly CIAM and B2B SaaS applications.

- **[Casdoor](https://github.com/casdoor/casdoor)** [![Stars](https://img.shields.io/github/stars/casdoor/casdoor?style=social&color=white)](https://github.com/casdoor/casdoor/stargazers) 🚪
  - **UI-first, open-source IAM and SSO platform** with WebUI support, Apache-2.0 licensed.
  - **Features**: OAuth 2.0, OIDC, SAML, CAS, WebAuthn, social logins, captcha verification, SMS/email OTP, plugin extension architecture, and multi-tenant organization management.
  - **Best for**: Cloud-native web applications needing a feature-packed out-of-the-box admin portal.

- **[Hanko](https://github.com/teamhanko/hanko)** [![Stars](https://img.shields.io/github/stars/teamhanko/hanko?style=social&color=white)](https://github.com/teamhanko/hanko/stargazers) ⚡
  - **Open-source authentication & user management solution for the passkey era**, AGPL-3.0 licensed.
  - **Features**: WebAuthn passkeys, social logins, passcode/OTP, Hanko Elements Web Components for embeddable UI, API-first microservice architecture.
  - **Best for**: Passkey-first and passwordless application authentication.

- **[LLDAP](https://github.com/lldap/lldap)** [![Stars](https://img.shields.io/github/stars/lldap/lldap?style=social&color=white)](https://github.com/lldap/lldap/stargazers) 🐘
  - **Lightweight LDAP server** written in Rust for minimal memory footprint, GPL-3.0 licensed.
  - **Features**: Simplified LDAP administration, clean web UI for user/group management, GraphQL API, low RAM usage, and easy Docker deployment.
  - **Best for**: Self-hosters wanting a simple LDAP directory server for authenticating services without OpenLDAP complexity.

- **[Kanidm](https://github.com/kanidm/kanidm)** [![Stars](https://img.shields.io/github/stars/kanidm/kanidm?style=social&color=white)](https://github.com/kanidm/kanidm/stargazers) 🦀
  - **Simple, secure, and fast identity management platform** written in Rust, MPL-2.0 licensed.
  - **Features**: Passkeys (WebAuthn), OAuth2/OIDC provider, Linux/Unix PAM & NSS integration with TPM offline auth, SSH key distribution, RADIUS gateway, and read-only LDAPS compatibility.
  - **Best for**: Modern Linux ecosystem identity, SSH key management, and zero-trust authentication.

- **[FreeIPA](https://github.com/freeipa/freeipa)** [![Stars](https://img.shields.io/github/stars/freeipa/freeipa?style=social&color=white)](https://github.com/freeipa/freeipa/stargazers) 🐧
  - **Integrated security information management solution** for Linux/Unix environments, GPL-3.0 licensed.
  - **Features**: Combines 389 Directory Server (LDAP), MIT Kerberos, Dogtag Certificate System (CA), NTP, DNS, and Active Directory trust integration.
  - **Best for**: Centralized enterprise Linux domain control and identity management.

- **[389 Directory Server](https://github.com/389ds/389-ds-base)** [![Stars](https://img.shields.io/github/stars/389ds/389-ds-base?style=social&color=white)](https://github.com/389ds/389-ds-base/stargazers) 🌲
  - **Enterprise-class LDAP server** developed by Red Hat, GPL-3.0 licensed.
  - **Features**: Multi-master replication, high-throughput read/write operations, fine-grained access control, web administration console (Cockpit plugin), and schema extensibility.
  - **Best for**: Mission-critical enterprise LDAP directory services handling millions of users.

- **[Apache Syncope](https://github.com/apache/syncope)** [![Stars](https://img.shields.io/github/stars/apache/syncope?style=social&color=white)](https://github.com/apache/syncope/stargazers) 🔄
  - **Open-source Identity Governance and Administration (IGA) platform**, Apache-2.0 licensed.
  - **Features**: Full user lifecycle management (provisioning/deprovisioning), Flowable BPMN 2.0 workflow engine, password self-service, audit logging, and connectors to database/LDAP/REST targets.
  - **Best for**: Enterprise identity governance, provisioning, and workflow automation.

- **[OpenDJ](https://github.com/OpenIdentityPlatform/OpenDJ)** [![Stars](https://img.shields.io/github/stars/OpenIdentityPlatform/OpenDJ?style=social&color=white)](https://github.com/OpenIdentityPlatform/OpenDJ/stargazers) ☕
  - **LDAPv3-compliant directory service written in Java**, CDDL-1.0 licensed.
  - **Features**: Multi-master replication, REST/JSON HTTP access to directory data, sub-millisecond query performance, pluggable storage engines (JDBC SQL, Cassandra/Scylla).
  - **Best for**: Enterprise LDAP directory infrastructure with HTTP REST API requirements.

- **[Kubidm](https://github.com/pando85/kubidm)** [![Stars](https://img.shields.io/github/stars/pando85/kubidm?style=social&color=white)](https://github.com/pando85/kubidm/stargazers) 📦
  - **Self-hosted identity management platform** adapted from Kanidm with container-focused deployment tools, MPL-2.0 licensed.
  - **Features**: Passkey/WebAuthn auth, OAuth2/OIDC SSO, RADIUS VPN integration, TPM offline auth, and SSH key management.
  - **Best for**: Containerized Kubernetes deployments of modern identity providers.

- **[UNITY IdM](https://github.com/unity-idm/unity)** [![Stars](https://img.shields.io/github/stars/unity-idm/unity?style=social&color=white)](https://github.com/unity-idm/unity/stargazers) 🔬
  - **Group, identity, and federation management solution**, BSD-3-Clause licensed.
  - **Features**: SAML2 (IdP & SP), OAuth 2.0 / OIDC, X.509 client certificates, group hierarchy management, account linking, attribute aggregation, and user registration workflows.
  - **Best for**: Federated research, academic environments, and scientific data portals.

- **[Perun](https://github.com/CESNET/perun)** [![Stars](https://img.shields.io/github/stars/CESNET/perun?style=social&color=white)](https://github.com/CESNET/perun/stargazers) 🏛️
  - **Identity & Access Management system for distributed research environments**, FreeBSD licensed.
  - **Features**: Virtual Organization (VO) management, enrolment workflows, account consolidation, resource provisioning, and multi-protocol federation support.
  - **Best for**: International research infrastructures, e-Infrastructures, and university federations.

- **[Univention Nubus](https://github.com/univention/nubus)** [![Stars](https://img.shields.io/github/stars/univention/nubus?style=social&color=white)](https://github.com/univention/nubus/stargazers) 🏢
  - **Modular open-source solution for centralized Identity & Access Management**, AGPL-3.0 licensed.
  - **Features**: Centralized web portal, SSO integration, user self-service, pre-built domain integration, scalable cloud/on-premise deployment.
  - **Best for**: Sovereign IAM in public sector institutions, schools, and enterprise IT.
